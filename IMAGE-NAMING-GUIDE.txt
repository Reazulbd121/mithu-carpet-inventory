MITHU CARPET — PRODUCT IMAGE RULE (CATEGORY + CODE)

সব ছবি images ফোল্ডারে রাখবেন। Excel/data.js-এ Photo column লাগবে না।

ছবি খোঁজার Priority:
1) Category + Product Code
2) Product Code
3) Product Name

উদাহরণ — একই Code দুই Category-তে থাকলে:

images/Prayer Carpet BG-01.jpg

images/BG-01.jpg

Code না থাকলে Product Name:
images/Classic 2x3.jpg

images/Carpet Tiles BG-01-3.jpg

.jpg .jpeg .png .webp

- পুরোনো Code/Name অনুযায়ী ছবিও চলবে।
- data.js, Stock, In/Out বা Search logic পরিবর্তন করা হয়নি।
